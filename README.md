

# HelloWorldLanguage (HWL)

**HWL** — это эзотерический язык программирования, созданный для максимально абсурдного и быстрого вывода и ввода данных.

## 🚀 Установка

Чтобы начать использовать HWL в своей системе, выполни следующие команды в терминале:

```bash
git clone https://github.com/saniqp64-byte/hw-lang.git
cd hw-lang
./install.sh

```

После этого команда `hwl` станет доступна глобально в твоем терминале.

---

## 📖 Синтаксис

Язык использует уникальную структуру `ввод(команда)`.

### Основные правила:

1. **Перенос строки:** Вместо стандартного `\n` используй символ `&`.
2. **Структура:** Каждая строка должна содержать команду в формате `аргумент(функция)`.
3. **Комментарии:** На данный момент не поддерживаются.

---

## 🛠 Доступные функции

| Функция | Описание | Пример использования |
| --- | --- | --- |
| `print` | Выводит переданный аргумент в консоль. | `Hello World(print)` |
| `input` | Ожидает ввод пользователя с клавиатурой. | `Введите данные(input)` |

---

## 💡 Примеры кода

### Пример 1: Приветствие

```text
Hello World(print)

```

### Пример 2: Использование переноса строк

Если нужно вывести текст в две строки:

```text
Первая строка & Вторая строка(print)

```

### Пример 3: Запрос данных

```text
Как тебя зовут?(input)

```

---

## ⚡ Как запустить программу

После того как ты создал файл с кодом (например, `main.hwl`), запусти его командой:

```bash
hwl main.hwl

```

---

## ⚠️ Известные ограничения

* Язык поддерживает **только** формат `ввод(команда)`.
* В данный момент синтаксис строго ограничен двумя функциями.
